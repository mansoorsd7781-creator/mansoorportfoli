## About

This is a single-page portfolio built from scratch with HTML, CSS, and JavaScript. It includes:

- **Hero section** — quick intro and stats
- **About** — education background
- **Skills** — C, Python, HTML, CSS, JavaScript
- **Featured Project** — [SMV Tyre Agencies](#), a 5-page business website I built for a real tyre shop
- **Resume download** — direct PDF download
- **Contact** — email and phone

## Built With

- HTML5
- CSS3 (custom properties, responsive grid, scroll-based animations)
- Vanilla JavaScript (Intersection Observer for scroll reveals, scroll progress bar)
- Google Fonts — Space Grotesk, Inter, JetBrains Mono

## Running Locally

No build step required — it's a static site.

```bash
git clone https://github.com/yourusername/your-repo-name.git
cd your-repo-name
```

Then just open `index.html` in your browser, or serve it locally:

```bash
python -m http.server 8000
```

## Deployment

Hosted on GitHub Pages. To deploy your own copy:

1. Push this repo to GitHub
2. Go to **Settings → Pages**
3. Set Source to **Deploy from a branch**, branch `main`, folder `/root`
4. Your live link appears in the same settings page after a minute
